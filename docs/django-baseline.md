## 项目信息

项目名称: **小型办公用品采购系统**

采购需求管理（员工提交采购申请：物品名称、规格、数量、用途；取消申请）；

审批管理（管理员查看采购申请，审批通过 / 驳回并填写理由；通过后标记 “已采购”）；

采购查询（员工查看自己的申请进度，管理员按审批状态、时间筛选所有申请）；

库存同步（管理员采购完成后，更新对应办公用品的库存数量，避免重复采购）；

### 4.1.7~9 注册, 获取, 更新员工信息

> **接口描述**
>
> - 注册一个员工, 只能由部门管理员以上权限的用户进行
> - 获取员工信息, 部门管理员可以获取部门下所有员工信息; 系统管理员可获取所有员工信息, 也可以筛选指定部门员工
> - 更新员工信息(无法更新work_id), 部门管理员可以更新部门下所有员工信息, 无法更新部门和权限信息; 系统管理员可更新所有员工信息, 以及部门和权限信息
>
> **接口URL**
>
> - `/api/users/workers/`
>
> **请求方式**
>
> - GET(获取信息) / POST(注册员工) / PUT(更新员工)
>
> **路径参数**
>
> 无
>
> **请求头部**
>
> | 参数名        | 必须 | 类型   | 说明      |
> | ------------- | ---- | ------ | --------- |
> | Authorization | 是   | string | JWT token |
>
> **请求体参数 Body-raw-JSON**
>
> GET:
>
> | 参数名 | 必须 | 类型   | 说明                     |
> | ------ | ---- | ------ | ------------------------ |
> | depart | 否   | string | 部门名称(仅限系统管理员) |

> | power   | 否   | string | 权限名称(仅限系统管理员) |
>
> PUT:
>
> | 参数名  | 必须 | 类型   | 说明                     |
> | ------- | ---- | ------ | ------------------------ |
> | work_id | 是   | int    | 工号                     |
> | name    | 否   | string | 名称                     |
> | email   | 否   | string | 邮箱                     |
> | phone   | 否   | string | 手机号                   |
> | working | 否   | bool   | 是否在职                 |

> | power   | 否   | string | 权限名称(仅限系统管理员) |

> {
>     "work_id": 25020002,
>     "name": "陆二二",
>     "email": "lua22@163.com",

>   - 部门管理员: 可以更新自己部门的普通员工
